# Electricity Review Lab

A study and practice web app for a Grade 7 science "Criteria A" electricity test.

**Open it:** download `index.html` and double-click it, or visit the GitHub Pages site if it's turned on for this repo.

## What's inside

**Study mode**
- Formula sheet: `P = I × V`, `P = I² × R`, `V = I × R`, `R = ρL ÷ A`, cover-up triangles, units and conversions
- Searchable key terms
- Flash cards (terms, formulas, symbols & units, circuit symbols, big ideas) with progress tracking
- Interactive visuals: Ohm's law water pipe, three ways to charge, series vs parallel, wire resistance, inside a battery, circuit symbols, reading graphs, lightning safety
- Links to PhET simulations and videos

**Practice Test**
- Every question from the review guide, untimed, with automatic checking
- Hints, show answer, per-question and whole-test reset, progress bar and filters
- Number answers accept working, units and scientific notation (`8.5 x 10^-8`, `8.5e-8`)
- Drawing tools that are checked automatically: circuit builder (Q6, Q7), charge model (Q2), battery model (Q4), Venn sorter (Q7), plus sketch pads

## How it works

One self-contained HTML file: plain JavaScript and CSS, no build step, no server. It works offline once opened (fonts fall back to system fonts). Answers and progress are saved in the browser's `localStorage`, so each person's work stays on their own device.
